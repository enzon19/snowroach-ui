# Snowroach UI

Yet another opinionated UI library for Svelte.

# Variants details

- solid: primary, no border
- soft: primary-soft, no border
- surface: primary-soft, primary border
- outlined: no bg, primary border
- ghost: no bg, no border, primary-soft on hover

# Tokens

## Size

- xs: h-8 px-3 text-xs
- sm: h-9 px-3.5 text-sm
- md: h-10 px-4 text-sm
- lg: h-12 px-4 text-base
- xl: h-14 px-5 text-lg
- 2xl: h-16 px-6 text-xl

## Border Radius
- components: lg
- containers: xl
